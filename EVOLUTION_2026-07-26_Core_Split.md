# Evolution Note — Core Split (Privacy & Ownership)

**Date:** 2026-07-26  
**Type:** System architecture / privacy & ownership  
**Status:** Active — perfect evolution of Train Your Dragon

---

## What changed

Clarified and enforced a hard split:

- **Dragon project (the system itself)** → GitHub only  
  Bootloader, skills, rules, official course skeleton, versioning, future web-launchable process.

- **Living personal work** → User’s PARA on Google Drive  
  All projects in progress, notes, research, study, journal, discoveries, faith work, equipment, etc.

- **Capture** → Dragon-Inbox (Drive root)  
  Phone → AI review → file into PARA.

**Privacy & ownership rule:** Data lives in the user’s PARA. It is not controlled by any AI system.

---

## Why this is an evolution

Earlier durability work had placed private notes and research under My-Dragon-AI (GitHub). That was useful for recovery testing but conflicted with the user’s standing PARA decision and the principle that personal data ownership must stay with the human.

Warrior’s Way personal study had already been migrated from GitHub to PARA for file-access speed. The same principle now applies system-wide for living work.

The bootloader and personal-notes skill were updated so they no longer treat private GitHub as the home for living personal material.
