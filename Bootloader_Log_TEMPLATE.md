# Bootloader Log — Template

**Living copy location (PARA):**  
`Projects/Train-Your-Dragon/Bootloader_Log.md`

**Rule:** Append only. Human owns the living file. This template is the system-side reference only.

---

## Entry format

```
### [YYYY-MM-DD HH:MM TZ] — [Instance label]
- Platform: [Android / Web / X / Voice / Other]
- Action: Launch | Bootload update
- Notes: [optional short note]
```

## Guidance

- Instance label is chosen by the human (or a sensible default on first ask).
- Keep notes short.
- Do not put private personal content in the log — only orientation metadata.
- Newest entries may be placed at the top or bottom; stay consistent with the living file’s convention.
